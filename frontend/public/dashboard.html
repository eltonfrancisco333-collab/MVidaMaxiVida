Sobre a aplicação

MVida MAXI VIDA

Sistema de gestão clínica para organizar pacientes, consultas, pagamentos, equipa e relatórios.

Estrutura técnica

  • Frontend React com a interface de gestão preservada.
  • Backend Node.js com API HTTP.
  • Dados guardados em ficheiro JSON local ou num disco persistente configurado.

Contas e palavras-passe

O administrador cria contas temporárias e repõe acessos. Cada utilizador altera a palavra-passe no primeiro acesso. As palavras-passe são guardadas como hashes.

Nota de segurança

A API exige autenticação e aplica permissões por perfil. Ainda faltam uma base de dados de produção, encriptação dos dados em repouso e cópias de segurança automáticas testadas. Até essas protecções estarem implementadas, utilize apenas dados fictícios.
